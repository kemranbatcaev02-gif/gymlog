## ✨ Ключевые возможности

- 📓 **Удобный дневник тренировок:**
  - Быстрая фиксация упражнения, рабочего веса, числа повторений, подходов, коэффициента усилия (RPE) и персональных заметок.
- 🏋️‍♂️ **Библиотека упражнений:**
  - Предустановленная база из 40+ классических упражнений с разбивкой по мышечным группам (грудь, спина, ноги, плечи, руки, кор) + возможность добавлять свои.
- 🔥 **Главный дашборд аналитики:**
  - Счетчик серии тренировочных дней (Streak), суммарный тоннаж за тренировку, частота занятий за неделю и умные подсказки под вашу цель (набор массы / сушка / поддержание формы).
- 📈 **Встроенные графики прогресса (Matplotlib):**
  - Визуализация роста рабочего веса, общего тренировочного объема и динамики 1ПМ для каждого конкретного упражнения.
- 🥇 **Автоматический трекинг рекордов:**
  - Фиксация максимального поднятого веса и расчетного 1ПМ с защитой от ручных ошибок ввода.
- ⚖️ **Контроль массы тела:**
  - Отдельный журнал взвешиваний с графиком колебаний веса во времени.
- 💾 **Экспорт данных в CSV:**
  - Экспорт всей истории тренировок в файл для анализа в Excel или Google Таблицах в один клик.
- 🎨 **Кастомизация UI:**
  - Переключение темной и светлой тем оформления, 5 стильных акцентных цветов интерфейса, выбор единиц измерения (кг / фунты).

## 🧮 Расчет одноповторного максимума (1ПМ)

Для расчета максимального теоретического веса на одно повторение в приложении используется признанная спортивная **формула Эпли (Epley formula)**:

$$\text{1ПМ} = \text{вес} \times \left(1 + \frac{\text{повторения}}{30}\right)$$

Формула позволяет безопасно оценивать силовой прогресс по рабочим подходам на 4–10 повторений без необходимости подвергать связки и суставы пиковым предельным нагрузкам.

## 📥 Установка и запуск

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/kemranbatcaev02-gif/gymlog.git
cd gymlog

# 2. Установите зависимости
pip install -r requirements.txt

# 3. Запустите трекер
python main.py
```

*При первом старте приложение предложит указать имя, текущий вес и тренировочную цель — под них автоматически адаптируются подсказки и статистика на дашборде.*
